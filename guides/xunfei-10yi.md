## 这是什么

讯飞星辰 MaaS 平台（maas.xfyun.cn）1024 开发者节活动：每人免费领 **10 亿 tokens**，额度挂在星火 Spark-X2.6 模型上。31 天倒计时从领取那一刻开始算，**晚领不如早领，领了就要马上用**。

## 领取步骤（5 步，10 分钟搞定）

1. **打开官网**：浏览器访问 https://maas.xfyun.cn ，手机号注册账号。
2. **实名认证**：登录后按提示做个人实名认证。⚠️ 界面会提示「1-3 个工作日」，实际实测**基本秒过**，不需要人脸识别、也不用传身份证（个人开发者认证即可，不用企业认证）。
3. **找到活动入口**：回到首页，找**「星火 X2.6 的活动」**入口卡片（领取弹窗/首页 banner）。如果没看到，先确认实名已通过。
4. **创建 API Key**：按弹窗指引创建一个 API Key（自己起个名字），创建完成即触发发放 10 亿 tokens。
5. **立刻去用**：额度挂星火 X2.6，支持 OpenAI 协议接入 Claude Code / Cursor / workbuddy 等编程工具：
   - API 地址：`https://maas-api.cn-huabei-1.xf-yun.com/v2/chat/completions`
   - 密钥：形如 `ak-xxxxxxxx`（就是你第 4 步建的 Key）
   - workbuddy 用户：直接让 AI 帮你配置自定义模型，配好会出现在模型选择列表最底部。

## ⚠️ 三大坑，务必看清

1. **勾选框陷阱（最重要）**：领取弹窗**上方有一个默认勾选框**——勾着的话，**免费额度用完会自动转按量计费扣你钱包里的钱**。领取前务必**取消勾选**再点确认。实测过的博主提醒：这额度消耗非常快（有人不到一天用完），一旦勾选很容易在不知不觉中产生扣费。
2. **31 天倒计时**：额度有效期从**领取之日起 31 天**（不是自然月），到期清零不补。领完就安排任务，别囤。
3. **消耗速度**：10 亿听起来很多，X2.6 是旗舰模型 + 编程 Agent 场景下上下文很长，重度使用一两天就能烧完。建议配额提醒，或把大任务放闲时跑。

## 红线

- 每人限领 1 次，需实名（一个实名主体一次）。
- 该额度仅限星辰 MaaS 平台模型服务，别与 Coding Plan 订阅（那是另一套 `maas-coding-api` 地址）混用。
