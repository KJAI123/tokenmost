## 领取步骤

1. **注册阿里云账号**（手机号即可）。
2. **进百炼控制台，地域选「华北 2（北京）」**：https://bailian.console.aliyun.com/ 。⚠️ 只有北京地域模型有免费额度，选错地域=白开。
3. **进「模型广场」，首次会弹服务协议**，阅读并同意 → 自动开通并自动发放，**无需手动领取**（没弹协议=早就开过了，额度已在）。
4. **等 2 小时**：额度生效可能延迟，有额度的模型会显示蓝色额度条。查余量三处：控制台「免费额度」页 / 模型广场 / 模型用量页（分钟级更新，手动刷新）。
5. **建 API Key 开用**：控制台「API-KEY」页创建，按官方接入文档配置（支持 OpenAI 兼容协议）；模型名直接填 `deepseek-v4-pro`、`kimi-k3`、`glm-5.3` 等即可。

## 两个合法放大技巧（官方规则内）

1. **快照版双份额度**：快照版（如 `qwen-max-2026-05-17`）与正式版 `qwen-max` 的额度**相互独立**——同一模型领两份是官方规则允许的。第三方模型同理可留意各自快照。
2. **OAuth 认证另享独立额度**：走 OAuth 方式调用另有**每天 2000 次**的独立额度，与 token 包分开计算。

## ⚠️ 90 天规则与防扣费

1. **有效期「自开通百炼 / 模型发布 / 模型申请通过之日（较晚者）起 90 天」**，过期清零不补发不延期。哪个模型发布晚，哪个就刷新 90 天——第三方新模型刚上架时额度最"新"。
2. **耗尽即停开关**：未实名账号默认开启「用完即停」且不可关；**已实名账号默认是关闭的**——想防超额去控制台手动打开（额度用完返回 HTTP 403，错误码 `AllocationQuota.FreeTierOnly`）。
3. 抵扣优先级官方口径：**免费额度 > 资源包 > 节省计划 > 按量付费**——别先买资源包，不然免费额度会"压箱底"过期。
4. 只抵实时推理：Batch/微调/部署/缓存存储费不在免费额度内。
5. **同实名主体重新注册账号不能重领**（官方明文）——这是测试过的死路，别浪费时间。
6. 限免模型（如 decision-model-preview、deepseek-r1-distill-qwen-1.5b）标注在定价页，随时可能收回。
