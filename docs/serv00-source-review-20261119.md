# Serv00 信源收录复核（2026-11-19）

目的：把已有发现线索补为可查、可申请的免费网页主机条目，说明审核与保活要求。

## 本轮改动

- 新增公开权益 `serv00-free-hosting` 与 Serv00 导航入口，归入独立云资源区；免费云资源目录由 21 项增至 22 项。
- 按官方免费档记录 3 GB SSD、512 MB 内存、最多 100 个网站及 SSH/数据库支持，保留原单位，不写入 Token 额度或购买力。
- 中文及英文简述直接标出人工审核、90 天内登录保活。审核通常数小时至 72 小时，一人限一号；条款限制网站、邮箱与代码仓库用途，禁止代理、VPN 和隧道。
- 添加 4 条官方证据、官方站点 Logo 和 3 个页面变更监控（均 `auto_verify:false`）；更新已有 `serv00-home` 发现源说明，不重复新增发现任务。
- 公开核验指官网配置与条款已核对，不代表账号已经开通，也不包含用户个人邮箱或注册资料。
- 页面验收发现英文顶部操作区在 390px 宽度溢出 7px：420px 以下将社群按钮文字收起，保留图标及无障碍名称，并更新样式版本。
