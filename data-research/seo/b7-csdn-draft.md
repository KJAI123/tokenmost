## 正文草稿

写代码调 API 的人最近应该有个共同感受：**模型价格在降，但额度福利在缩**。2026 年平台集体从「白送」转向低价订阅，单个活动窗口越来越短。这篇把官方渠道还活着的免费额度按使用场景盘一遍，全部条目核实于 2026-11-14，过期不候。

### 场景一：日常对话/文档处理

- **DeepSeek**：网页/App 免费；API 错峰 5 折（北京工作日白天以外全模型）+ 缓存命中低至 0.04 元/百万——夜间跑批量，成本可以压到忽略不计。
- **通义千问**：客户端「工作」模式 5 小时滚动试用额度，到点自动恢复；订阅会员可续跑。
- **豆包电脑版**：天天领额度活动长期在场（签到+任务，30 天/笔），官方明禁多号。

### 场景二：AI 编程/Coding Agent

- **智谱系**是当前力度天花板：GLM-5.3-Flash 每日可领 3 亿（Weekend Build 升级为每日放量）；ZCode 客户端 11-13 起每人 5 亿新礼包。
- **美团 LongCat**：560B 开源旗舰 API 每天白给 5000 万 token，OpenAI/Anthropic 双协议。
- **MonkeyCode**（长亭开源）：免费档每日 1000-3000 万 token，口径以控制台为准。
- **Cline 免费档**：免 Key 免绑卡，登录即用 DeepSeek V4.1 Flash/Kimi/GLM；**OpenCode Zen** 免费池 10 款全 $0，连缓存读取都不计费。

### 避坑（都是真案例）

- 中转站「注册送 $100」是站内币不是美元，能跑什么模型以它家分组为准；
- 「不限量」套餐看历史：讯飞星辰 3.9 元无忧版集体退款在先；
- 淘宝代充/永久会员=钓鱼或违反 ToS，官方渠道永远第一。
