## 知乎（主力，Lv3）✅ 已运转

### 排版规范
- 编辑器 Draft.js：不支持 Markdown——**编号清单用「1、2、3」纯文本**，段落空行分隔
- 逐行 insertText + Enter（\n 不换行坑）；连续列表行会被自动加 bullet
- 每条带「截至 X 年 X 月核实」= 可信度信号

### 风控规则
- **回答 ≤2 条/天**（新号期减半；邀答池题目=官方邀请，不算主动灌水）
- 每题独立角度，禁止跨题复制——两天 20+ 条零风控验证过「邀答池+独立内容」安全
- 草稿自动保存，但发完再关标签（编辑态丢失=重写）

### 流量活动
- ✅ **创作打卡挑战赛**（五十四期→五十五期已报名，11-20 接棒）：每日 1 创作任务+3 互动任务，全勤 28 天奖励翻倍
- 圆桌收录（Token 经济学）：邀答题被圆桌收录=额外流量
- 创作分 267→涨分加速：日更回答+想法+评论

## CSDN（百度权重最高）🚨 禁言冻结中

### 排版规范
- Markdown 编辑器：完整支持 #/##/**bold**/- 列表——**排版必须用语法渲染**（纯文本=没排版）
- 标题 5-100 字；正文用「### 小节」分段；标签必填 3 个
- React setter 法写标题（input 隐藏 w=0）；正文 contenteditable 逐行输入

### 风控红线（⚠️ 血泪：Lv1 新号 3 天 5 篇同主题带外链=禁言）
- **新号首发期（前 2 周）：每周 ≤2 篇**
- 主题必须多样化：羊毛盘点/技术教程/工具评测轮换，禁止连续同主题
- 外链密度：每篇 ≤1 个，且不能每篇都带；tokenmost 用纯文本提及优先
- 禁言状态下系统会清编辑器内容——冻结期不做任何编辑动作
- 解封流程：产品反馈表单+官方博客私信+udesk 客服三通道（已验证有效）

### 流量活动
- 首次发文任务、GEO 检测工具、GitCode 同步备份（白赚曝光）
- 审核期 24-48h 正常；「审核未通过」=主题踩线（域名薅羊毛类被拒过）

## 通用纪律

1. **频率**：新号首发期减半；同平台禁止连发同主题
2. **外链**：每篇 ≤1 个；tokenmost 自然植入（纯文本提及优先于 markdown 链接）
3. **时效**：每条带「截至 X-X 核实」；过期内容主动更新
4. **原创**：一稿多投必须每平台改写 30%+；禁止复制粘贴
5. **申诉三通道**（CSDN 模板）：产品反馈表单+官方博客私信+udesk 客服
6. **cookie 迁移**：老板 Chrome 登录 → Storage.getCookies → 9223 无头（会话过期时重跑）
