想记笔记又不想花钱？Obsidian 加两个开源搭档，编辑、画图、随身阅读全齐，一分钱不用花。以下组合截至 2026-11-20 核实。

一、第一件：Obsidian 本体，个人使用免费

笔记是本地 Markdown 文件，双向链接和关系图谱自带，数据在自己硬盘里，不绑账号、不怕停服。官方收费的只有同步和发布服务，核心功能一个不少。【核实日期：2026-11-20】

二、第二件：Drawio 插件，笔记里直接画图

流程图、架构图不用另开软件：装社区插件 Drawio，笔记里双击图形就能编辑，图和文字存进同一个库，依旧是本地文件。零成本。【核实日期：2026-11-20】

三、第三件：Calibre，把笔记变成随身电子书

笔记攒多了，选中导出成文档，用开源的 Calibre 批量转换成电子书格式，推到手机阅读器或电纸书上，通勤路上就能复盘一个月的积累。【核实日期：2026-11-20】

四、同步的免费替代

官方同步服务收费，免费路线两条：把笔记库放进 Git 私有仓库，配自动提交插件，顺手白得历史版本回滚；或者用开源同步工具在设备间点对点直连，不经过第三方服务器。多端是刚需再考虑付费，单机党一分钱不用花。

五、避坑两条

第三方插件装之前看更新时间和维护状态，停更太久的不建议上；同步方案先拿小目录试一周，确认无误再全量搬进去。
