我一直有个执念：笔记这种东西，数据必须攥在自己手里。之前一个朋友用的在线笔记软件突然改收费，想导出几年的笔记还得先开会员，听他吐槽完我更坚定了。所以今天说说 Obsidian 加两个开源搭档的免费组合，编辑、画图、随身阅读全齐，一分钱不用花。这套组合我 11-20 又核对过一遍，都还是老样子。

先说本体。Obsidian 个人使用免费，笔记是本地 Markdown 文件，双向链接和关系图谱都是自带的，数据就在自己硬盘里，不绑账号，也不怕哪天停服。官方收费的只有同步和发布这两项服务，核心功能一个不少，等于白嫖了整个主体，很良心了。

第二个搭档是 Drawio 插件，管画图。流程图、架构图不用另开软件：装上社区插件 Drawio，笔记里双击图形就能编辑，图和文字存进同一个库，依旧是本地文件。零成本，画完顺手还能嵌在笔记里，懒人狂喜。

第三个是 Calibre，管「随身阅读」。笔记攒多了，选中导出成文档，用开源的 Calibre 批量转换成电子书格式，推到手机阅读器或者电纸书上，通勤路上就能复盘一个月的积累。我个人特别喜欢这一步，有种把知识打包带走的爽感。

哦对，还有同步的免费替代。官方同步服务收费，但免费路线有两条：把笔记库放进 Git 私有仓库，配个自动提交插件，顺手还白得历史版本回滚；或者用开源同步工具在设备间点对点直连，不经过第三方服务器。多端是刚需再考虑付费，单机党一分钱都不用花。

最后提个醒，两条避坑，都是经验之谈：第三方插件装之前看一眼更新时间和维护状态，停更太久的不建议上；同步方案先拿小目录试一周，确认无误再全量搬进去，别上来就梭哈。
