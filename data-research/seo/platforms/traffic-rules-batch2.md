# 平台流量分发规则研究 · 第二批（掘金 / CSDN / 简书）

> 研究日期：2026-11-19。方法：WebSearch 公开信息检索（未使用浏览器登录）。部分平台官方规则页未被搜索引擎索引，标注为推断/待站内核实。

## 一、掘金（Juejin）

### 【流量分发机制】
- 首页推荐为算法分发。历史上核心指标是「互动率」：点击率、点赞、评论、收藏。近期（信息流大调整后）推荐权重重新分配——平台明确降低纯互动导向（争议性、情绪化、易消费内容易刷互动的漏洞），转向「内容价值回归」，深度技术文章获得更多曝光。
- 收藏/点赞/评论的比例结构本身也被算法读取：收藏远高于点赞且评论少 → 判定为「深奥、完读人少」，影响后续推荐。
- 互动数据信号解读参考：[掌握掘金文章推荐算法](https://juejin.cn/post/7331684753664131123)；推荐机制调整解读：[掘金信息流大调整（CSDN）](https://www.csdn.net/detail/webblog_31478210/133802)、[从流量优先到内容价值回归（CSDN 专栏）](https://wenku.csdn.net/column/y3551gso8xb)。
- 沸点是轻内容流量池，互动门槛低，适合新号曝光和涨粉，但不计入文章类掘力值主线（推断，需站内确认）。

### 【权重因子】
1. 掘力值（创作活跃度得分）——影响作者权重与文章初始流量。
2. 文章平均点赞/阅读/评论数（完读率、互动质量重于互动总量）。
3. 专栏活跃度（持续更新专栏的作者获得加权）。
4. 文章标签匹配度（Lv2 起可加多标签，标签决定分发垂类）。
5. 粉丝数与粉丝互动率。
6. 创作等级（Lv1–Lv8+）决定权益池。

### 【新号冷启动要点】
- 先用沸点 + 「新人创作礼」活动积累首波互动和等级（ Lv2 达 100 掘力值，解锁双标签）。
- 标签必须精准：新号没有粉丝分发，标签垂类是唯一初始入口。
- 首篇文章选题偏向「可完读」的中等深度教程（配图、代码可复现），兼顾新算法的「内容价值」导向和完读率。
- 矿石体系：签到、发文、被赞/收藏、参与活动获得矿石，在权益中心兑换周边/优惠券/抽奖——矿石是活跃激励不是现金收益；等级（Lv1–Lv6+）随活跃度增长，对应徽章与权益。权益入口在个人中心（站内「权益中心」）。

### 【当前活动清单】
- **金石计划**：征文激励活动，面向 Lv4–Lv8 创作者，2025 年多期举办且「奖金升级、玩法升级」；2026 年新期次暂未见官方公告，需盯掘金活动栏目。（参考：[在AI与Vibe Coding时代，用创作塑造你的影响力](https://juejin.cn/post/7643427666948866094)）
- **新人创作礼**：面向新人的常设创作激励，2026 年 10 月的文章仍在挂标参与，是新人最确定的活动。
- **训练营类活动**：门槛适中、反馈快（金石计划同源生态）。
- 官方规则参考：[创作等级&掘力值全新升级公告](https://juejin.cn/post/7125658251852513294)、[社区等级与权益调整公告](https://juejin.cn/post/6981103809099464711)。

### 【可执行建议】
1. 新号第一周：签到 + 3 条沸点 + 1 篇挂「新人创作礼」标签的文章，冲 Lv2。
2. 文章结构优化「完读率」：短段落、目录、可运行代码块——直接对应新算法的内容价值分。
3. Lv4 后立即参加金石计划（奖金最确定的中高级活动）。
4. Lv7 解锁课程写作权限，作者分成约 70%，是掘金变现上限最高的路径。
5. 建专栏并保持周更：专栏活跃度是长期流量权重的复利项。

## 二、CSDN

### 【流量分发机制】
- **分级推荐池**：文章发布后，若初始数据（完读率、收藏率）高于领域均值，算法推入二级、三级推荐池 → 首页推荐、领域置顶、热门榜单曝光，流量指数级放大（参考：[CSDN 博客流量提升技巧](https://blog.csdn.net/weixin_72849553/article/details/163593012)）。
- **热榜**：各领域热榜（首页/今日热榜可追踪）按近期热度词排名；上榜内容反过来成为选题风向标——用热榜近 7 日热词 + GitHub Trending 交叉验证选题是公认打法（参考：[高流量文章创作全攻略](https://blog.csdn.net/wx_qutudy/article/details/149025392)）。
- CSDN 在百度/搜索引擎的 SEO 权重极高，长尾技术词的自然搜索流量是老文章的持续来源。

### 【权重因子】
1. 完读率、收藏率、点赞、评论（决定推荐池升级）。
2. 三套等级体系：
   - **博客等级**（15 级，积分 = 原创 + 访问 + 评论 + 点赞）；
   - **创作等级**（LV1–LV4+，关联付费资源/付费专栏发布门槛）；
   - **原力等级**（综合创作与互动的「原力分」，衡量影响力，解锁高阶权限、活动参与权、曝光加权）。
3. 原创声明/原创认证（收益权益的前提）。
4. 领域垂直度与关键词 SEO 命中。

### 【新号冷启动要点】
- 先完成原创认证 + 冲创作等级 LV1–LV4（约 4 周可达付费资源发布门槛）。
- 选题跟热榜热词，标题带精确长尾关键词（CSDN 流量大头来自搜索）。
- 单篇阅读量破万若未开付费专栏/付费资源，直接收益为零——冷启动期先堆等级和原创标，再谈变现。
- 等级体系详解：[博客等级体系全解析](https://blog.csdn.net/m0_63456023/article/details/149537029)、[原力创作者三大等级体系](https://developer.aliyun.com/article/1532179)。

### 【当前活动清单】
- **SoduWork 项目测评创作者招募**（CSDN 官方，blog.csdn.net/blogdevteam）：测评 SoduWork（Agent 协作开发工具），总奖金池 10 万+，已有大量博主发实测文章参与。**当前最值得参加。**
- 2026 年 1024 程序员节征文（获奖名单已公布，活动收尾）。
- 开学季等季节性征文（专栏聚合可见）。
- 常规：付费资源上传分成、付费专栏、内容流量奖励。

### 【流量分成 / 收益】
- **付费专栏**：2023-09-01 起改为**阶梯分润**——比例不固定，按作者累计收入和博客/原力等级动态调整；起步约 50%，但累计收益 ≥30 万时作者分成降至约 10%（社区争议大，参考：[分润新机制揭秘](https://blog.csdn.net/2301_78153627/article/details/169851665)、[掘金批评文](https://juejin.cn/post/7410587194274938931)）。
- **付费资源/文库**：上传资源按下载分成。
- **广告分成**：App 内不支持直接设置；变现靠内容流量奖励 + 付费专栏 + 活动补贴（[CSDN 文库问答](https://wenku.csdn.net/answer/d4d8jha5nt3mj)）。
- 付费专栏建议 15–30 篇成体系（[内容变现指南](https://blog.csdn.net/weixin_44256994/article/details/128534836)）。

### 【可执行建议】
1. 立即参加 SoduWork 测评征文（奖金池大、门槛低、官方流量扶持）。
2. 标题按「热榜热词 + 长尾搜索词」双优化，正文保完读率冲二级推荐池。
3. 第一阶段目标：原创认证 + 创作等级 LV4（约 4 周），解锁付费能力。
4. 付费专栏规模化前算清阶梯分润账：累计收益越高分成越低，适合中小体量作者，头部收益被平台截留。
5. 同一内容可分发付费资源（文档/代码包）做二次分成。

## 三、简书

### 【流量分发机制】
- **中心化编辑/专题推荐，非纯算法**：文章发布后向专题投稿，由专题主编审核收录；入选首页推荐或大专题 = 主要流量来源（参考：[「简书」困局](https://www.woshipm.com/operate/384472.html)）。
- **每篇文章最多投 5 个专题**，且投稿机会一次性消耗——专题选择即流量策略，热门专题（如首页投稿、读书、故事）流量大但审核严，垂直专题过稿率高（参考：[简书运营 4 招](https://www.sohu.com/a/359797051_723902)、[简书运营策略](https://zhuanlan.zhihu.com/p/364689712)）。
- 推荐链路：用户反馈数据初筛 → 编辑审核 → 首页/日报推荐；持续优质产出可获「简书推荐作者」官方名号与加权。

### 【权重因子】
1. **专题主编的收录决定**（权重最大的人工因子）。
2. 文章的点赞/评论反馈数据（初筛依据）。
3. 简书钻持有量：点赞权重与持钻量挂钩，持钻多的「创作者」身份点赞收益更高（参考：[知乎：简书怎么赚钱](https://www.zhihu.com/question/547472423/answer/2632266263)）。
4. 日更达人徽章、简书创作者徽章等身份信号。

### 【新号冷启动要点】
- 每篇只用 5 次投稿机会里 2–3 次投大专题、其余投垂直小专题，保证至少 1 个收录拿到初始曝光。
- 文风向「故事化、可读性」靠拢——简书读者偏好叙事型内容，硬技术文收录率低。
- 争取「简书创作者」徽章提升收录率与权重。

### 【收益体系：简书钻 / 简书贝 / FTN】
- 2018 年起与 Fountain（FTN）区块链项目绑定（注意：是 Fountain/FTN，与已破产交易所 FTX 无关）。
- 简书钻 = 权重证明，简书贝 = 可交易/提现部分，两者 1:1；阅读/点赞越多获得简书钻越多，钻可兑换人民币。
- 现实衰减严重：刷量失控后平台导向氪金——持钻越多评价权重越高，收益向付费用户和互赞圈集中（参考：[简书留下的乐子（掘金）](https://juejin.cn/post/7292297423166472228)）；写作收益已很低，**提现门槛 100 元起**（参考：[知乎专栏](https://zhuanlan.zhihu.com/p/3193270030)）。
- 结论：简书收益体系不可作为主要变现渠道，只作分发渠道。

### 【当前活动清单】
- **日更挑战**（官方常设，[活动页](https://www.jianshu.com/mobile/campaign/day_by_day/join?from=home)）：按**累计日更天数**发放日更达人徽标（20 天、100 天等分级）；徽标有效期 **365 天**，升级到更高级徽标时有效期刷新；中断即失败（有复活卡机制，以官方页为准）。
- **简书创作者徽章**申请（身份认证类）。
- 站内专题征文不定期，需站内关注专题公告。

### 【可执行建议】
1. 把简书定位为「多平台分发的最末位渠道」：一稿多发的 SEO 补充位，不投入独家内容。
2. 参加日更挑战攒徽章（低成本、提升账号权重与收录率），但内容可用短篇/随笔，不必耗精品。
3. 投稿策略：大专题（首页/故事）+ 垂直小专题组合，先保收录再求爆款。
4. 不投入真金买简书钻——收益体系已泡沫化，提现门槛 100 元且权重向氪金用户倾斜。
