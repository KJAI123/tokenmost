## 一、小红书

### 【流量分发机制】
- **四大流量入口**：发现页（推荐流，双列瀑布流）、搜索、关注、热门（[2026小红书流量算法分析](https://zhuanlan.zhihu.com/p/2065500863221724709)）。双列瀑布流的直接推论：**封面图+标题=点击率生死线**，笔记能否被点开决定后续一切。
- **流量池递进**：2026 年算法重构后，所有新笔记统一进入 **200–500 的初始种子流量池**，新老账号起跑线一致；数据达标逐级放大（[2026最新推荐机制与实操攻略](https://kuku.baidu.com/landing/tscp_doc/b956689092eaccee381c3abc069933ad)）。
- **2026 三大算法变化**：①AI 语义理解深度升级（NLP 提取标题/封面/正文/话题关键词打标签，匹配用户兴趣标签，标签越精准触达越有效）；②用户行为预测模型优化；③内容质量评估体系重构（[搜狐 2026-01-20](https://www.sohu.com/a/977900996_121147659)）。
- **从"平权分发"转向"贡献力分发"**：垂直账号互动率低于 5%、停留时长不达标会被切断后续推荐；算法从"流量赛马"转向"价值输出"。
- **搜索是长期流量**：建议选择竞争度小、流量大且精准的关键词布局标题与正文。

### 【权重因子】
| 因子 | 权重说明 |
|---|---|
| 点击率 | **2026 年权重最高的考核指标**（封面+标题决定） |
| 互动率（赞/藏/评） | 流量池晋级核心；收藏价值尤其高（种草属性） |

| 关键词布局 | 搜索流量的基础；标题/正文/话题标签一致性强加分 |

### 【当前活动 / 付费流量】
- **薯条**（官方自助加热工具）：起投约 60 元（750 薯条）；**只能加热"非商业的优质内容"**，营销内容审核不过；建议投发布 30 天内、自然数据已起步的笔记；两个投放目标（曝光量/互动量）；**笔记点击率需 >2% 才获得持续推荐**。参考：[薯条功能解析（新榜）](https://a.newrank.cn/trade/news/1477)、[薯条审核规则（MarketUP）](https://marketup.cn)。

### 【违规词体系 / 红线】（TokenMost 重点）
- **高危词类别**：绝对化用语（最/第一/顶级/国家级）、虚假承诺（100%有效/根治/无效退款）、医疗功效词（非医疗资质账号）、**金融敏感词（赚钱/暴富/兼职收益/返利）**、引流词（微信号/加V/私聊/扫码）。检测工具：**零克查词**（lingkechaci.com）、句易网、[蒲公英违禁词检查开源项目](https://github.com/jidarin9383/banned-words-check)。
- **站外导流零容忍**：《交易导流违规管理细则》禁止商城/购物车/官方留资组件之外的任何站外交易引导，**最高永久封号**；处罚阶梯：第一次警告 → 第二次限流+禁言 7 天 → 第三次加重（[2026引流红线解析](https://cn.ezagency.com.au/online-marketing-strategy/xiaohongshu-wechat-lead-generation-tips)、[GEO智库避坑指南](https://geozhiku.com/research/xiaohongshu-private-traffic-compliance-2026)）。
- **限流自检**：正常账号首页推荐流量应占 50%+；多条笔记小眼睛 <100、流量主要来自关注页 = 已限流（[导流警告处理案例](https://zhuanlan.zhihu.com/p/489263432)）。

### 【可执行建议】（TokenMost 视角）
1. 羊毛快讯类内容在小红书是**"金融敏感词 + 站外导流"双重高危区**：表达必须"去营销化"——包装成"省钱攻略/白嫖教程"笔记体（emoji 分段、清单式正文），绝不出现微信号/外链/"赚钱/返利"字样。
2. 发布前用零克查词过一遍全文；封面自行设计（不直接搬运商家海报，避免广告判定+点击率低）。
3. 起号先垂直：只发一个品类（如"信用卡权益/话费充值"），贡献力分发下杂散发反而稀释账号权重。
4. 数据好的笔记（点击率 >2%）再用薯条小额加热放大，60 元即可测试。

### 【入场门槛】
- 注册：手机号即可；实名认证后解锁完整互动功能，是开通专业号的前提。
- **个人专业号**：注册+实名即可申请，免费（获得数据后台/商单/店铺能力）。
- **企业专业号**：营业执照+认证公函+商标证，约 600 元/年审核费，获蓝V。
- ⚠️ 批量接码注册属违规灰色操作，封号风险极高；一机一卡一号为安全实践。

## 二、B站（bilibili）

### 【流量分发机制】
- **阶梯式流量池**：新视频先进入几百至几千曝光的初始池，**48 小时内的完播率、互动率决定能否晋级**；完播率 >40% 且点赞率 >5% 时，约 7–13 小时进入大范围推荐池；约 10% 优质内容可获 1–30 天长尾二次推荐（[B站视频流量规则与避坑指南 2026-03 更新版](https://www.bilibili.com/opus/1174639200035667972)）。
- **2025 年底算法大改：三连率成为核心指标**——三连率 <5% 大概率卡初始池；5%–8% 进小池；**>8% 进中大型流量池**；**>15% 触发全站推荐/有机会上首页**（[算法大改三个月，三连率成新流量密码](https://post.smzdm.com/p/ae6rgp9m)）。
- **2026-03-31 下线"猜你喜欢"，废除旧算法**：官方称打破信息茧房、给优质多元内容更公平的入口；新算法细节尚未公布（执行中需持续观察推荐位变化）。
- **推荐指数历史公式**（36氪 1000 条数据拆解，供参考）：硬币×0.4 + 收藏×0.3 + 弹幕×0.4 + 评论×0.4 + 播放×0.25 + 点赞×0.4 + 分享×0.6，**新发布 24 小时内权重×1.5**（[36氪拆解](https://m.36kr.com/p/1370788824887686)）。分享权重最高，前 24 小时是黄金期。

### 【权重因子】
| 因子 | 权重说明 |
|---|---|
| 三连率（赞+投币+收藏）/播放 | 新核心指标；>8% 进中大池，>15% 全站推荐 |
| 完播率 | >40% 晋级线（对短视频型内容更严） |
| 分享 | 推荐指数公式中权重最高（×0.6） |
| 弹幕/评论/硬币 | 各 ×0.4，社区氛围信号 |
| 更新频率/内容质量 | 计入创作激励金额计算 |

### 【新号冷启动】
- **新星UP扶持计划**（官方长期活动）：首稿奖金 + 千万级流量 + 社群服务 + 成长扶持，新人第一站。
- **视频播客扶持政策**（2025-07 暑期）：10 亿级冷启动流量，扶持播客视频化、专家学者、垂直领域创作者，上线视频播客专属 AI 工具。
- 冷启动本质：初始池（几百–几千曝光）→ 48h 数据考核 → 晋级。新号前 5 稿的完播/三连数据决定账号初始标签。

### 【当前活动 / 收益体系】
- **创作激励计划**：门槛 1000 粉 + 实名认证 + 原创自制稿件播放达 1000 后开始计收益；约 1–3 元/千播放（另一口径 1000 播放 5–50 元浮动，[变现指南2025](https://www.google.com/goto?url=CAESaAHEIkXXerPQTz2Wj9UNbGKi6hKwNlGgyHRnwMRNxxx6VOLF40xW3wt6SH1r8SGeD1IZm0s86GZhAz2rLqQdmDUc1YyKXnHJr0Ne_jhMSu-M9eYUkMidWZZl0cP9q6XZ7_khyB5Qj6Re)）。⚠️ **2025 年下半年后激励门槛大幅提高**：粉丝 <1 万的账号需同时满足三连率 >8% 且完播率达标才有基础激励收益；9 月爆款小目标等任务已取消。
- **充电计划**（打赏）：观众打赏电池，硬币按 10:1 折算，贝壳系统按月结算，UP 主约拿七成；历史开通门槛 1000 粉+实名（以创作者中心当前规则为准）。
- 激励按月根据近半年收入水平综合计算（内容质量/用户互动/更新频率），[视频创作激励年度计划（2024版）官方规则](https://www.bilibili.com/opus/910081674283319305)。

### 【专栏 vs 视频】
- **专栏**=正式图文文章：可被站内搜索、有独立收益体系、沉淀在个人空间"专栏"tab；**动态图文（opus）**=社交动态：流量依赖粉丝和推荐流，门槛更低。
- 专栏/图文收益单价低于视频，推荐逻辑中**互动（赞/评/藏）权重高于阅读量**；视频有完播率+三连率考核维度，推荐池机制更成熟但激励门槛已大幅提高。
- 首页推荐位类型：已关注、高赞、新星计划、关注的人赞过、广告（[一文带你看懂B站视频推荐](https://www.bilibili.com)）。

### 【可执行建议】（TokenMost 视角）
1. B站用户对"薅羊毛/省钱"内容接受度高（数字生活区传统品类），但**视频才是主流量与变现载体**；图文专栏/opus 作为低成本测试场与长尾搜索补充。
2. 前期目标不是激励收益（门槛已提高），而是**新星UP扶持计划的流量+奖金**：新号第一稿就走活动入口。
3. 视频脚本设计三连钩子（"这期整理成了清单，三连自取"）；前 24 小时（权重×1.5）集中发布+社群引流首发。
4. 2026-03 新算法上线初期是流量洗牌窗口，多元垂类内容相对红利。

### 【入场门槛】
- 注册：手机号简单注册；**转正需答题**（100 题答对 60 题及格）才解锁投币/评论/投稿完整权限。
- **实名认证**：2017-07 起上传视频（新增/编辑/换源）必须先实名；国内用户绑国内手机号验证；**一个实名只能绑一个 B 站账号**（本人使用，支持改绑）。
- 创作激励：1000 粉 + 实名；知名UP主认证：10 万粉+互动良好。

## 三、抖音 / 西瓜视频

### 【流量分发机制】
- **2026 算法变化**：完播率逐渐退出核心位置，**深度互动 + 搜索价值**成为新权重重点；**收藏权重提升**——实用价值内容比纯情绪内容更容易拿到流量（2026-04 行业分析）。
- **冷启动机制**：不再依赖"养号"，通过**前十条视频的数据校验**快速建立人群模型；新视频过审后分配初始流量池（约 200–500 在线用户），按曝光数据+账号分值决定晋级。
- **流量层级**：抖音电商已合并自然流量池与付费流量池，层级为 E 至 S 六级（爱复盘《流量池层级规则》2026 版）。
- **图文赛道（TokenMost 关键机会）**：抖音 2025 年官宣**超四成流量倾斜图文赛道**，2026 继续加码优质图文扶持；图文带货拥有**独立流量池**（[2026优质图文扶持计划全攻略](https://kuku.baidu.com/landing/tscp_doc/828eaf475880a7a54eb980e54cdd9e10)、[图文带货新红利分析](https://zhuanlan.zhihu.com/p/1988995913549648836)）。历史验证：#抖音图文来了 话题播放量突破 611 亿、参与博主超 1000 万。
- **西瓜/中视频计划已终结**：原"中视频伙伴计划"（1 分钟横屏门槛）**2024-09 下架**（9-18 最后一次发放收益），升级为**"创作者伙伴计划"——取消时长与横竖屏限制**，原创竖屏视频、图文内容均可产生收益，西瓜/抖音/头条三平台打通（[升级说明](https://zhuanlan.zhihu.com/p/718067874)）。2026 年无恢复原计划迹象，西瓜扶持思路转向"流量分成"。

### 【权重因子】
| 因子 | 权重说明 |
|---|---|
| 前 3 秒留存 | 起号五大核心数据之首 |
| 深度互动（评论/转发） | 2026 新核心（完播率降权） |
| 收藏 | 权重提升中，实用价值内容红利 |
| 搜索价值 | 文案第一句与视频开头一致可获搜索流量 |
| 账号分值 | 与曝光数据共同决定初始池晋级 |

### 【新号冷启动】
- 前 10 条内容做"数据校验"，建立人群模型——起号期选题宁窄勿宽。
- 发布后 1 小时内找 5–8 个真实好友完播+点赞+评论破冷启动池；**不要用互赞群（判定刷量）**。
- 图文起号成本低于短视频：3–5 图+清单式文案即可成稿，配合平台四成流量倾斜。

### 【当前活动 / 收益】
- **创作者伙伴计划**（抖音+西瓜通用）：门槛实名认证 + 粉丝 1000/5000 档位；**低粉豁免通道**——完成原中视频计划且累计收益 ≥50 元、年满 18 岁、发布过 20 条以上无广告原创视频、近 90 天零违规者可加入。
- 收益方式：内容展示广告的创作分成，与播放/阅读量挂钩；另有图文带货（独立流量池）、站内图文活动话题的官方流量奖励。
- 抖音持续做图文流量激励活动（"围猎"小红书抢图文用户），活动入口在创作者中心/活动广场。

### 【可执行建议】（TokenMost 视角）
1. **图文赛道是本轮扩张性价比最高的机会**：平台四成流量倾斜 + 制作成本低于视频 + 收藏权重上升利好"清单式羊毛攻略"内容。
2. 把快讯改写成"3–5 张图 + 首图文案即结论"的抖音图文体；标题埋搜索关键词（"XX银行 信用卡 权益 2026"）。
3. ⚠️ **一证一号是矩阵化最大瓶颈**：一个身份证只能实名一个抖音号且不可解绑/转移，矩阵只能走企业号/员工号（营业执照）或合规的多主体注册——扩张前先规划账号主体结构。
4. 变现顺序：创作者伙伴计划分成 → 图文带货佣金 → 商单。

### 【入场门槛】
- 注册：手机号即可；**实名认证（一证一号）**才能解锁直播、提现等实名功能，认证不可更改不可解绑。
- 多账号官方通道：企业号/员工号（需营业执照）。
- 收益计划：实名 + 粉丝门槛（1000/5000 档）或低粉豁免通道；网传"一证多号"技巧已失效且有封号风险。

## 四、知乎想法 · 算法与违规判定补充（v4 策略依据）

### 【流量分发机制】
- 想法是**短内容通道**，分发以**关注关系的社交分发为主 + 部分推荐流**；与回答不同：回答有"问题自带流量 + 搜索流量"，想法没有问题页面承接，纯靠关注链与推荐（[知乎内容分发策略解析](https://www.google.com/goto?url=CAESaQHEIkXXQJWhoalVmqGq_HRvJGVAhMavqBWFU_HQmGDNLtl-bcuc-GkxbfzmBRMyOxgoFNUwxEkqivs6C3cIOJBHMgssebBoIGfRQbrmaNyH8q4GLIzNQgQkG_Tt49idpJbWO7EWuNsunw)、[营销枢纽](https://www.google.com/goto?url=CAESiwEBxCJF16uBPGqoRljnE90l9VqC52EntL_yi0BYBJLNL4G8PA6OUFoRSjrNyEf9cYqIjU0LZdWXE4ItKNWyEc2VddPlq3MBvk-t-dnJcKu8HRdrC1oDhHbaLFuDfQsVUsYznVrYGF4ExSZrpveaTsUCCHP_XzsCYBjQJHiWnlD66pIHyZKNn...)）。
- 有用户实测想法阅读量可明显高于回答（2023 讨论），说明想法存在独立推荐通道，但**该通道对内容形态敏感**（见下）。

### 【违规判定机制：为什么羊毛快讯式想法被判"垃圾营销"】
**知乎官方风控明确打击的三类行为特征**（[官方治理实例合集](https://zhuanlan.zhihu.com/p/611842590)、[风控对抗特征](https://zhuanlan.zhihu.com/p/62525083)）：
1. **单位时间发帖量上限**——官方明说对"发帖量大的重复内容生产者"做频次限制；
2. **粘贴行为识别**——对有粘贴行为的用户做识别（快讯类内容天然是复制粘贴产物）；
3. **行为特征风控**——登录/注册/发布的模式化异常检测（机器人特征）。

**内容侧触发特征**（机器审核，秒删非人工，[被判删案例](https://zhuanlan.zhihu.com/p/618016762)、[误判讨论](https://www.zhihu.com/question/586326712)）：
- 推广性内容：收益记录/收益截图、"加微信"、外链、二维码；
- 高频 + 模板化重复 = 典型"垃圾信息与违规营销"画像。

**处罚阶梯**：内容删除 → 按次数与严重程度禁言 1/7/15 天或永久 → 连带账号锁定；申诉多由机器人处理，成功率低。

### 【v4 策略推论】（供策略文档引用）
1. **想法不能用作快讯广播通道**：高频+模板化+粘贴 恰好命中风控全部特征，被判垃圾营销不是误伤而是必然。
2. 若使用想法：**降频**（远低于单位时间上限）、**每条独立重写**（不复制粘贴）、**去收益截图/外链/营销词**。
3. 想法的正确定位是**"流量搭桥"**——转发优质回答/文章送出圈（批次1已验证），而非独立高频产出通道。
4. 快讯类高频产出需求应迁移到无此类风控的载体（自家 RSS/邮件列表，或批次4 中西瓜图文/抖音图文等图文分成通道）。
