# TokenMost 流量规则研究 · 批次1（知乎 / 百家号 / 头条号）

> 研究日期：2026-11-19。信息来源：公开网络检索（知乎专栏、官方帮助中心、行业媒体）。规则随平台迭代变动，执行前建议在官方后台二次确认。

## 一、知乎

### 【流量分发机制】
- **排序核心是威尔逊得分（Wilson Score）算法**：按"赞同率 + 置信区间"计算得分，而非绝对赞同数。公式参数：u=赞同、v=反对、n=总票数、p=赞同率、z=正态分位数。这避免了少量赞同的回答排在多数赞同之前，也意味着**早期反对票对排名杀伤极大**。
- **流量池递进机制**：新回答先进入小流量池，系统根据阅读完成率、赞同、评论、收藏等互动数据决定是否推入更大流量池（典型的赛马机制）。
- **投票权重不等价**：高盐值用户、优秀回答者标识、领域大V的赞同对排名提升远大于普通用户；高权重用户的反对也同理。
- **搜索场景叠加 SEO**：站内排名还受关键词匹配、收藏、分享影响；知+（付费投放）可加权。知乎内容在百度/Google 收录权重高，长尾搜索流量可观。
- **"想法"是流量外挂通道**：当回答被锁定流量受限时，转发到"想法"可以把内容送出圈（社区实测"流量搭桥"玩法）。

### 【权重因子】
| 因子 | 权重说明 |
|---|---|
| 赞同（高权重用户） | 最高，尤其大V/高盐值账号 |
| 反对 | 负向权重显著，早期反对票压制排名 |
| 阅读完成率 | 流量池晋级的关键阈值指标 |
| 评论 | 中等，评论区活跃度计入 |
| 收藏/感谢 | 中等偏上，搜索排名也计入 |
| 盐值（0–1000） | 账号可信度核心指标；初始 260–300，随专业/友善行为增减，影响个人投票权重 |

### 【新号冷启动要点】
1. **垂直定位**：前几篇内容决定账号初始标签与权重，宁精勿多；冷启动关键不在日更，而在前几篇吸引精准粉。
2. **答新题/潜力题**：选提问时间新、竞争回答少的题，蹭威尔逊算法"少票也可排前"的红利。
3. **引导互动**：结尾抛问题引评论；评论必回，拉互动数据进下一级流量池。
4. **快速升创作等级**：发 2 分钟以上知识类视频，每条约 +150 创作分；约 20 条到 Lv4（3000 分）解锁大部分收益权益（共 26 项权益，Lv8 基本拿全）。
5. **养盐值**：完善资料、专业回答、友善互动、举报违规内容均可加盐值。
6. **一稿多用**：长文拆短分发到想法、多平台引流（公众号/小红书联动）。

### 【当前活动清单】（2026 年检索到的进行中/近期活动）
- **知乎圆桌**（zhihu.com/roundtable，长期入口）：回答圆桌问题，普遍奖励 = 流量扶持（1万–10万曝光）+ 盐粒瓜分 + 超赞包。
- **"AI 投研与交易"线上圆桌**（2026.9.7–9.30）：回答圆桌问题并转发到想法，获流量奖励 + 盐粒。
- **2026 人文季"本来就很棒的人类"**：填表投稿即时获流量扶持；50+ 篇优质投稿被圆桌收录，瓜分 50 万盐粒。
- **香港城市记忆圆桌**：带话题提问/回答圆桌问题，优质内容 1 万–10 万流量扶持。
- **CES 相关圆桌**：被收录回答获 5000 曝光"超赞包"，瓜分 20 万盐粒。
- **2026 短篇故事影响力榜**：新上榜圆桌，适合故事类内容。

### 【可执行建议】
1. **变现路径**：好物推荐（门槛最低，Lv 达标后创作权益开通，回答/文章/视频插商品卡拿佣金）→ 致知计划（盐粒，100 盐粒=1 元）→ 盐选专栏（故事类高收入）→ 付费咨询。
2. **圆桌是 TokenMost 相关的天然流量入口**：金融/投研/AI 类圆桌（如"AI 投研与交易"）与产品受众高度重合，优先参加，回答后必转发"想法"做流量搭桥。
3. **执行节奏**：冷启动期（前 2 周）每天 1 条 2 分钟+视频 + 1 个垂直回答；目标 2 周内 Lv4，解锁好物推荐与流量权益。
4. **避坑**：不刷赞（高权重反对反噬）、不答与账号标签无关的热题（污染账号画像）、早期避免争议话题招反对票。

## 二、百家号

### 【流量分发机制】
- **双引擎分发**：内容审核后进入百度搜索 + 手机百度资讯流（+ 好看视频），AI 精准匹配，搜索与资讯流日曝光超百亿。本质是"推荐流 + 搜索流"双通道，**搜索长尾流量占比高于纯推荐平台**。
- **推荐晋级逻辑**：与主流信息流一致——小流量测试看点击率、完读率/完播率、互动率（分享/评论），数据达标进入更大流量池。
- **实测数据**（2026.2 新榜）：含数据来源标注、行业资质背书、原创图表/实拍素材的内容，7 日平均完播率高出普通内容 37%，推荐池进入率提升 2.1 倍——**可信度信号是百度特有的加权项**。
- **AI 摘要时代新规则**：百度 AI 摘要使流量向"被引用来源"集中；未被 AI 摘要引用的文章点击率下降。内容需结构化、权威、易被 AI 抽取引用。

### 【权重因子】
| 因子 | 权重说明 |
|---|---|
| 点击率（CTR） | 标题+封面决定第一波测试成败 |
| 完读率/完播率 | 核心指标；参考同类平台阈值：<30% 推荐终止，>65% 加大推送 |
| 互动率（分享/评论） | 晋级二级流量池依据 |
| 原创度 | 百家号指数的原创分维度；原创标签门槛 |
| 垂直度 | 账号领域聚焦度，影响领域匹配分发 |
| 信用分 | 违规扣分影响全部权益 |
| 可信度信号（数据来源/资质/实拍） | 百度特色加权，显著提升进池率 |

### 【新号冷启动要点】
1. **新手期已取消**（2020.11 起）：无需转正，新作者入驻即享创作收益；权益改为**按粉丝量级**解锁（30 余项权益）。老规则（注册 7 天 + 指数 500 + 信用分 100）仅作历史参考。
2. **快速解锁原创标签**：转正状态 + 内容质量分 ≥500 + 原创分 ≥800 + 历史发文原创占比高——原创标签直接拉高分发与单价。
3. **选题命中搜索需求**：用"三圈黄金选题法"（用户真实需求 × 搜索量 × 自身领域）；推荐量高阅读低 = 选题错位。
4. **内容可信度包装**：每篇都带数据来源标注、行业资质、原创图表/实拍图。
5. **为 AI 摘要优化**：结构清晰（小标题+要点列表）、开头直给结论，争取被 AI 摘要引用截流。

### 【当前活动清单】（2026.11 检索）
- **百家号创作者激励计划**（持续进行，2026.11 仍在更新）：优选计划第 52 期榜单、百家榜每月更新。参与条件：实名认证 + 信用分 ≥80。
- **百家知识分享季**（2026 全年，双周为一期，如首期 1.1–1.15，期末 1 周公布奖励）：百家号 APP → 任务中心 → 征文活动 → 立即参与 → 发布图文。
- **泛知识内容征集**（知识分享季 7 大亮点话题，全年滚动）。

### 【可执行建议】
1. **TokenMost 主阵地之一**：百度搜索是"crypto/代币/钱包工具"类长尾词的主要入口，知乎+百家号双覆盖搜索结果页。
2. 每篇文章按"结论前置 + 小标题结构 + 数据来源标注"模板写，同时服务完读率与 AI 摘要引用。
3. 优先参加**知识分享季征文**（双周一期，门槛低、有保底流量扶持），保持信用分 ≥80 以维持参与资格。
4. 节奏：每周 3 篇垂直图文（金融科技/加密工具教程），30 天内冲原创标签。

## 三、头条号

### 【流量分发机制】
- **四层推送机制**：冷启动（小范围测试）→ 数据晋级（CTR/互动达标进下一级）→ 多级放量 → 长尾流量。2026 年算法升级后**长尾效应增强：优质内容发布 7 天后仍可获推荐**。
- **双列流/双标题逻辑**：内容以标题+封面进入双列瀑布流，用户先做"点击与否"的决策——**标题与封面的 CTR 是第一道生死线**。双标题功能（一篇内容两套标题分别测试）是官方提供的 A/B 工具。
- **消重机制**：系统对标题/封面/正文相似度高的内容限流，只推最优一篇——**搬运/洗稿在头条基本没有出路**，一稿多发需做差异化改写。
- **四类核心特征**（官方架构师披露）：相关性特征、环境特征、热度特征、协同特征；冷启动阶段热度特征权重尤其高（蹭热点有效）。
- **话题二次分发**：微头条带 # 话题进入话题页，多一个曝光入口。

### 【权重因子】
| 因子 | 权重说明 |
|---|---|
| 点击率（标题×封面） | 双列流第一指标 |
| 互动率（评论/点赞/转发） | 晋级依据；微头条靠互动加速 |
| 账号垂直度 | 影响标签匹配精度，垂直号推荐量稳定 |
| 发布时间 | 影响冷启动测试窗口的初始数据 |
| 热度特征 | 冷启动期蹭热点可显著加权 |
| 首发声明 | 影响分成倍数（见下） |

### 【新号冷启动要点】
1. **微头条是新号涨粉首选**：门槛低、流量池大、比长文更易进推荐、更易涨粉。
2. **发布即声明"首发"**：单篇声明首发即加入首发激励计划，符合要求的内容按阅读量享 **3 倍分成**（2025.6 规则升级后门槛降低为单篇声明制）。
3. **用双标题 A/B 测试**：两个标题分别进流量池测 CTR，保留数据好的方向。
4. **避开消重**：与知乎/百家号的一稿多发必须改标题+调整开头结构+替换配图。
5. **保持垂直**：领域漂移会导致推荐量忽高忽低；冷启动期发内容前先想清账号标签。
6. **善用"头条加油包"**：后台【工具】中的流量助推工具，可用于优质内容追加曝光。

### 【当前活动清单】（2026.11 检索）
- **首发激励计划**（长期）：单篇声明首发 → 3 倍分成。官方规则：https://baike.toutiao.com/detail/242/566/0
- **头条加油包**（长期工具）：流量助推，后台【工具】开通。https://mp.toutiao.com/docs/baike/2789/44827
- **新星创作计划**：平台邀请制，微头条写得好可获 4 倍额外创作收益。
- **优质创作者计划**（2025 大会延续）：加入后优质创作者流量扶持至少翻倍；2025 起平台提高准入门槛，打击博眼球/泛虚假/低质水文——**深度干货内容受益**。
- **创作者计划成长体系**（长期）：权益 + 信用分规则。https://mp.toutiao.com/docs/baike/2789/37620

### 【可执行建议】
1. **变现杠杆最大的一招是"首发激励"**：同一内容如果要发头条，务必声明首发拿 3 倍分成；但首发要求头条优先发布，与知乎/百家号的分发顺序要做排期（建议头条首发 → 24-48h 后差异化改写发知乎/百家号，规避消重也规避知乎判定营销）。
2. **内容组合**：每日 1-2 条微头条（带 # 话题，养互动与粉丝）+ 每周 2-3 篇深度长文（双标题测试，声明首发拿 3 倍分成）。
3. **长尾红利**：2026 算法下优质内容 7 天后仍获推荐，深度教程类内容（TokenMost 使用教程/行情分析）值得持续投入，不必只追时效热点。
4. **避坑**：不做搬运洗稿（消重必限流）、不碰"博眼球/泛虚假"（2025 起强治理，扣信用分影响全部权益）。
