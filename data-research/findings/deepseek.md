# DeepSeek — 调研发现

- **核实时间**: 2026-10-27
- **核实方式**: WebSearch（官方 API 文档为第一来源）
- **数据可信度**: 高（峰谷机制与调价日期多源一致；逐模型精确单价需查官方页）

## 结论（可直接进 deals.json）

无注册赠送，卖点是**长期低价 + 峰谷分时计价**：缓存命中输入低至 **¥0.02–0.15/百万 tokens**，缓存未命中空闲时段 ¥1/M 起（Flash 档）；高峰时段（09:00–12:00、14:00–18:00）价格上浮。**薅法 = 错峰 + 用缓存**。

## 明细

| 项目 | 空闲时段 | 高峰时段 |
|---|---|---|
| 输入（缓存命中） | ¥0.02–0.15/M | ¥0.04–0.30/M |
| 输入（缓存未命中） | ¥1–4.5/M | ¥2–9/M |
| 输出 | 至高 ¥9/M（Flash 档） | 至高 ¥27/M（Pro 档） |

- 2026-08-17 起正式执行峰谷分时定价（V4 Flash / V4 Pro 双档）
- 无新用户赠送；适合作为"全网比价基准线"条目
